## Step 2 — How customers pay

### Option A — WhatsApp (works NOW, no setup)

1. Customer clicks **Get Started** on a plan
2. They fill name + WhatsApp number
3. They tap **Order via WhatsApp**
4. You receive the message and send payment details

**No Stripe, no server needed.** This works on GitHub Pages today.

---

### Option B — Card / Apple Pay / PayPal (later, when you want)

You need:
1. Free account at [stripe.com](https://stripe.com)
2. Copy 3 keys from Stripe dashboard
3. On your computer, open Terminal in this folder and run:

```bash
./start.sh
```

Or deploy on [Railway.app](https://railway.app) — connect GitHub repo, add Stripe keys in Settings.
